Обезличивание и перевод CIM XML

Скрипт на Python для анонимизации и перевода моделей энергосистем (стандарт МЭК 61970). Убирает персональные данные и реальные названия объектов, чтобы файл можно было безопасно отдать на тестирование или разработку. Структура XML и связи между элементами не ломаются.

Как работает:
- Потоковое чтение. Файл разбирается по тегам через `iterparse` и сразу выгружается из памяти, поэтому можно прогонять большие выгрузки на несколько гигабайт.
- Одинаковые замены. За счёт хеширования (MD5) одно и то же название везде меняется на одно и то же вымышленное. Связи в схеме сохраняются, а хранить таблицы соответствий не нужно.
- Подмена по типам данных:
  - Для подстанций, ЛЭП и юрлиц генерятся новые названия через `pymorphy3` (из встроенного списка слов), приставки вроде `ПС`, `ТП`, `ООО` не трогаются.
  - ФИО, адреса и почты меняются на шаблонные.
  - В телефонах, ИНН, паспортах и лицевых счетах подменяются цифры с сохранением длины и скобок/дефисов.
  - В комментариях и логах числа затираются звёздочками, внутренние ссылки меняются на заглушки, а вложения в Base64 (картинки, PDF) вычищаются.
- Перевод. Если включить в настройках, скрипт переводит текст через `deep-translator`. Повторяющиеся слова запоминаются в кэш, чтобы не дёргать переводчик по сто раз.

Файлы
- `main.py` — основной скрипт.
- `config.json` — конфиг (пути к файлам, язык перевода и флаг вкл/выкл).
- `input.xml` — исходный файл.
- `output.xml` — результат.
